About the Exam

The Online Examination System is a simple web-based application created to conduct an examination through the internet. This test is mainly based on Internet Programming concepts such as HTML and CSS. Students can read each question, select the correct answer from the given options, and complete the examination.

Exam Details

  • 10 questions
  • Multiple choice questions
  • Topics include HTML and CSS

Instructions

  • Read each question carefully.
  • Choose one answer for each question.
  • Do not refresh the page during the exam.
